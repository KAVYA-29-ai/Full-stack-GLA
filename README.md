# 🎨 HTML & CSS Practice

A collection of **HTML5 and CSS3 practice projects** created while learning and strengthening the fundamentals of modern web development.

This repository contains multiple hands-on examples covering **CSS layouts, Flexbox, CSS Grid, positioning, responsive design, backgrounds, images, cards, navigation bars, dashboards, and UI components**.

---

## 🚀 Tech Stack

### Frontend

* **HTML5** — Structure and semantic markup
* **CSS3** — Styling, layouts, spacing, colors, and visual effects
* **Flexbox** — One-dimensional layouts and alignment
* **CSS Grid** — Two-dimensional layouts
* **CSS Positioning** — `static`, `relative`, `absolute`, `fixed`, and `sticky`
* **Responsive Web Design** — Flexible layouts and screen-size adaptation
* **CSS Backgrounds** — Background images, sizing, positioning, and attachment
* **CSS Box Model** — Margin, border, padding, and content
* **CSS Transitions & Hover Effects** — Interactive visual effects
